# Data Model: Inventory

## Enum `StockMovementReason` (`CategoryProduct.API/Models/StockMovementReason.cs`)

`Initial`, `Restock`, `Adjustment`, `Damage`, `Return`, `Sale`, `OrderCancelled`. Stored as the enum name string. Helper `StockMovementReasonExtensions.AdminReasons` = { `Restock`, `Adjustment`, `Damage`, `Return` }. `Sale` and `OrderCancelled` are reserved for feature 019; `Initial` is written only by `ProductController.Post`.

## Entity `StockMovement` (`CategoryProduct.API/Models/StockMovement.cs`)

| Property | Type | Rules |
|---|---|---|
| `Id` | int | PK |
| `ProductId` | int | required FK to `Products`, `OnDelete(Cascade)` |
| `Product` | `Product?` | navigation (no collection on `Product`) |
| `QuantityChange` | int | signed, never 0 (enforced by API) |
| `QuantityAfter` | int | quantity right after this movement, >= 0 |
| `Reason` | `StockMovementReason` | `HasConversion<string>()`, `HasMaxLength(30)`, required |
| `Note` | string? | `HasMaxLength(200)` |
| `UserId` | int? | FK to `Users`, `OnDelete(SetNull)` |
| `User` | `User?` | navigation |
| `CreatedAtUtc` | DateTime | set to `DateTime.UtcNow` by the service/controller |

Index: `HasIndex(m => new { m.ProductId, m.CreatedAtUtc })`.

## Changes to `Product`

`public Guid ConcurrencyStamp { get; set; } = Guid.NewGuid();` configured in `OnModelCreating` as `modelBuilder.Entity<Product>().Property(p => p.ConcurrencyStamp).IsConcurrencyToken();`. Regenerated by `InventoryService` on every stock change. Not regenerated by `PUT` (a PUT never writes quantity); a PUT whose UPDATE hits a changed stamp raises `DbUpdateConcurrencyException` and returns 409.

## `ApplicationDbContext`

`public DbSet<StockMovement> StockMovements { get; set; }`.

## Migration

`dotnet ef migrations add AddInventory --project CategoryProduct.API` creates table `StockMovements` (FK `ProductId` cascade, FK `UserId` set null, index) and adds `Products.ConcurrencyStamp` (non-null `uniqueidentifier`, default `00000000-0000-0000-0000-000000000000` for existing rows). Not hand-edited. Existing products have no movements. SQL Server accepts the table: cascade only from `Products`, set null from `Users`, no shared cascade path.

## Configuration

`Inventory:LowStockThreshold` (int, default 5, in `appsettings.json`). Bound by `InventoryOptions`; `Effective` maps negative to 5. Low stock means `Quantity < Effective`.

## State rules

- After any successful stock change: `product.Quantity == movement.QuantityAfter`, and for products created after this feature, `sum(QuantityChange) == Quantity`.
- Movements are never updated or deleted by the API; they disappear only with their product.
